# Лабораторная работа №10-11. Создание приложения «Список студентов» с использованием Material Design

Material Design — это система дизайна, разработанная Google для создания
качественных цифровых продуктов для Android, веб и других платформ. Она
предоставляет рекомендации по созданию читабельного, привлекательного и
согласованного пользовательского интерфейса.
Material Design основан на принципах:

- Материальность — интерфейс ведёт себя как физические объекты
- Смелость, графичность, осмысленность — использование цвета,
типографики и пространства
- Движение — анимации и переходы создают понятность
---

## Цель работы

Научиться применять принципы Material Design в Android
приложениях с использованием Jetpack Compose. В результате лабораторной работы
будет создано приложение «Список студентов», которое демонстрирует использование
цветовых схем, типографики, форм и анимаций Material Design

---

## Функциональность приложения

Приложение умеет следующее:

- Отображать **список из 10 студентов** с фотографиями (или иконками), именами и возрастом.
- Автоматически подстраиваться под **системную тему** (светлую или тёмную).
- Показывать **анимированное раскрытие карточки** при клике на иконку низ/верх — внутри появляется юмористическое описание студента.
- Использовать **единый стиль** во всём интерфейсе: цвета, шрифты, скругления.
- Работать на устройствах с **API 25+**.

---

## Технологии и библиотеки

| Компонент | Технология |
|-----------|-------------|
| Язык | Kotlin |
| UI-фреймворк | Jetpack Compose |
| Дизайн-система | Material Design 3 (Material 3) |
| Цвета и темы | `Color.kt`, `Theme.kt` (кастомная палитра) |
| Шрифты | Abril Fatface (заголовки), Montserrat (основной текст) |
| Анимация | `animateContentSize()` + `spring` (пружинная анимация) |
| Иконки | Material Icons Extended (`ExpandMore`, `ExpandLess`) |
| Управление версиями | Git + GitHub |
